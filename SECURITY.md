# Sicherheit

Das Projekt öffnet Netzwerkdienste auf dem PC (DSU über UDP, den Moonlight‑Stream von Apollo). Im Direktmodus betreibt es außerdem einen eigenen WLAN‑Access‑Point für das GamePad.

Melde Sicherheitslücken bitte **nicht** als öffentliches Issue. Nutze stattdessen [„Report a vulnerability“](https://github.com/Mendeln00/lichii-wiiu-gamepad/security/advisories/new). Die Meldung sieht nur der Maintainer.

Unterstützt wird nur der aktuelle Stand von `main`.
